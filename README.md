# DEMO
A LISP routine for AutoCAD that automates Walker Macy's standard demo layer process, making it faster and easier to manage demo layers, alternates, etc. in AutoCAD.

## How to load a LISP routine
- Type "APPLOAD"
- Select .lsp file
- Click **Load**

## Commands
DEMO       - Move selected objects to layers using the configured suffix.

UNDEMO     - Move selected objects from suffixed layers back to existing base layers.

DEMOCONFIG - Change suffix, color, no-plot setting, and optionally purge empty demo layers.
